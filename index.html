Controles

  • W / ↑ andar para frente
  • S / ↓ dar ré (andando para frente, primeiro freia)
  • Soltando as teclas o carro para sozinho · Espaço freia forte
  • A D / ← → girar o volante (ou arraste o volante na tela)
  • Enter terminar e ver a avaliação
  • C trocar câmera · V olhar para trás · Z / X olhar para os lados
  • T linha de trajetória · G marcação da vaga · M som
  • Backspace recomeçar · Esc menu

Dando ré: volante para a direita → a traseira vai para a direita (e a frente abre para a esquerda).

      Simulador de Estacionamento

      Treine a ré: o volante vira para um lado, a traseira vai para o mesmo lado e a frente vai para o outro.
